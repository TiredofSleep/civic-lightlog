# GRAVEYARD: ideas that don't work, and why

| idea | why it fails | do this instead |
|---|---|---|
| Make every plate read public "for transparency" | light on the data itself is a stalking tool; transparency belongs on *access* | the edge forgets; only hotlist hits are kept, and every access is public |
| Publish the hotlist as hashed plates to keep it private | only a few million plate formats exist; anyone can hash them all in minutes | publish the hotlist openly (stolen-vehicle lists often are), or keep it on the device under tamper evidence |
| Rely on encryption to protect a central plate database | the premise: assume it breaks, leaks or is read by an insider | don't build the database |
| A single "verified ✓" badge computed by the server | the server is exactly what might be lying | every viewer runs the audit itself; paper fingerprints for humans |
| A public "was my plate searched?" box | the search itself reveals who is interested in which plate | ask through the clerk; the request is logged |
| Rely only on the camera's clock | clocks drift and can be set | clerk-issued nonces at clock-in, plus witnessed checkpoints |
